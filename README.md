# VisionAI 🔍

An AI-powered Computer Vision web app built with React + Vite, powered by Groq (Llama 4) API.

## Features

- 🖼️ Image Description
- 🔎 Object Detection  
- 📝 OCR / Text Reading
- 🎬 Scene Analysis
- 🎨 Color Palette Extraction
- ✨ Custom Query

## Tech Stack

- React + Vite
- Groq API (Llama 4 Scout)
- Custom React Hooks
- Vanilla CSS-in-JS

## Getting Started

1. Clone the repo
   git clone https://github.com/prachi-nayak18/visionai.git

2. Install dependencies
   npm install

3. Add your Groq API key in .env file
   VITE_GROQ_API_KEY=your_key_here

4. Run the app
   npm run dev
